========================================
DISPOSITIVO: SW3
ROL: Switch de servicios (LAN servidores)
FUNCIONES:
- Conectar servidor, WLC y APs
- Red plana (sin VLANs)
========================================

DESCRIPCIÓN:
SW3 conecta los servicios principales de la red como el servidor DNS,
DHCP, AAA y el controlador inalámbrico. Funciona en una LAN única
(192.168.32.0/24).

CONFIGURACIÓN:

enable
configure terminal
hostname SW3

! --- IP de gestión ---
interface vlan 1
 ip address 192.168.32.2 255.255.255.0
 no shutdown
 exit

ip default-gateway 192.168.32.1

! --- Puertos en modo access ---
interface GigabitEthernet0/1
 switchport mode access
 spanning-tree portfast
 no shutdown
 exit

interface GigabitEthernet0/2
 switchport mode access
 spanning-tree portfast
 no shutdown
 exit

interface FastEthernet0/1
 switchport mode access
 spanning-tree portfast
 no shutdown
 exit

interface FastEthernet0/2
 switchport mode access
 spanning-tree portfast
 no shutdown
 exit

interface FastEthernet0/3
 switchport mode access
 spanning-tree portfast
 no shutdown
 exit

interface FastEthernet0/4
 switchport mode access
 spanning-tree portfast
 no shutdown
 exit

end
write memory
